# 돌봄 근무일지 캘린더

돌봄 근무 중 **무슨 일을 했는지, 어떤 특이사항이 있었는지**를 날짜별로 기록하고,
**해설사 근무표**(https://haeseolsa-schedule.vercel.app/)의 내 근무를 같은 캘린더에 함께 보여주는 웹페이지입니다.

- **상단에서 골라 보기**: `전체` · `돌봄` · `근무` · `일정` (+ 직접 추가한 메뉴).
  여러 개를 함께 켤 수 있고, 켜진 메뉴를 다시 누르면 꺼집니다. `전체`는 모두 다시 켭니다.
- **한 줄 일정**: 시간과 한 줄 글만 적는 가벼운 기록. 캘린더 칸에 한 줄로 나타납니다.
- **메뉴 편집**: 「병원」·「개인」처럼 한 줄 일정 메뉴를 늘리고, 모든 메뉴의 색을 바꿀 수 있습니다.
- **공휴일 표시**: 설·추석·대체공휴일·선거일까지 날짜를 빨갛게 하고 이름을 적습니다. (2025~2027년)
- **월 90시간 확인**: 월 90시간을 넘으면 추가 급여가 없으므로, 캘린더 위에 **90시간까지 남은 시간**을 크게 보여줍니다.
  넘으면 초과 시간을 빨갛게 알려주고, 일지를 쓸 때도 "저장하면 ○시간"을 미리 보여줍니다.
  (시작 · 끝 시간이 있는 일지만 계산 · 같은 날 겹치는 시간은 한 번만)
- **근무표와 동기화**: 해설사 근무표와 같은 데이터베이스를 읽습니다. 근무표 앱에서 근무를 바꾸면 이 캘린더에도 몇 초 안에 반영됩니다.
- **김태순 님 전용**: 이름 고르기 없이 근무표 앱과 같은 PIN 4자리로 로그인하고, 김태순 님의 근무만 가져옵니다.
  (명단에서 찾는 이름은 `VITE_OWNER_NAME`, 화면에 보이는 이름은 `VITE_DISPLAY_NAME` · 기본 "권희")
- **PC는 웹, 휴대폰은 안드로이드 앱(APK)**: 기록이 구글시트에 있어 둘을 함께 써도 같은 내용이 보입니다.
- **저장 · 백업은 구글시트**: 돌봄 일지 · 일정 · 메뉴는 김태순 님 구글 계정의 구글시트에 저장됩니다.
  시트를 열어 바로 보고 인쇄할 수 있고, `파일 → 버전 기록`으로 예전 상태도 되돌릴 수 있습니다.
- **김태순 님만 열람**: 구글시트는 요청마다 김태순 님 로그인인지 확인합니다. 연결 주소가 알려져도 다른 사람은 읽거나 쓸 수 없습니다.
- **휴대폰 ↔ PC 반영**: 다른 기기에서 쓴 일지는 창으로 돌아올 때, 또는 1분 안에 나타납니다.

## 1. 구글시트 연결 (한 번만)

> 연결하기 전에도 앱은 열리고 근무는 보입니다. "구글시트가 아직 연결되지 않았습니다" 안내만 뜹니다.

### 1-1. 시트와 스크립트 만들기
1. **김태순 님 구글 계정**으로 새 구글시트를 만듭니다. (이름 예: `돌봄 근무일지`)
2. 메뉴 `확장 프로그램 → Apps Script`
3. 기본으로 있는 `Code.gs` 내용을 모두 지우고, **[google-apps-script/Code.gs](google-apps-script/Code.gs)** 내용을 통째로 붙여넣은 뒤 저장(💾)

### 1-2. 스크립트 속성 넣기
Apps Script 왼쪽 `⚙ 프로젝트 설정` → 맨 아래 `스크립트 속성 추가`

| 속성 | 값 |
|---|---|
| `SUPABASE_URL` | `.env` 의 `VITE_SUPABASE_URL` 값 |
| `SUPABASE_ANON_KEY` | `.env` 의 `VITE_SUPABASE_ANON_KEY` 값 |
| `ALLOWED_EMAIL` | 앱 `[설정]` 화면의 **로그인 계정** 값 (예: `a02@guide.local`) |

### 1-3. 웹 앱으로 배포
1. 오른쪽 위 `배포 → 새 배포` → 유형 선택(⚙)에서 `웹 앱`
2. **실행 사용자: 나** · **액세스 권한: 모든 사용자**
3. `배포` → 권한 승인
   (계정 선택 → `고급` → `(프로젝트 이름)(으)로 이동` → `허용`. 직접 만든 스크립트라 나오는 경고입니다)
4. 나오는 **웹 앱 URL** (`https://script.google.com/macros/s/…/exec`) 복사

> "모든 사용자"여도 안전합니다. 스크립트가 요청마다 `ALLOWED_EMAIL` 로그인인지 확인합니다.

### 1-4. 앱에 주소 넣기
- 휴대폰 앱과 PC 웹에서 각각 `설정 → 구글시트 연결 주소`에 붙여넣고 **저장하고 연결 확인**
  → "연결되었습니다"가 나오면 끝입니다. (`구글시트 열기`로 시트로 바로 갈 수 있습니다)
- 또는 `.env` 의 `VITE_SHEET_API_URL` 에 넣고 빌드하면 기기마다 넣지 않아도 됩니다.

### 시트 모양 · 주의
탭 세 개가 자동으로 생깁니다.

| 탭 | 들어 있는 것 |
|---|---|
| **돌봄일지** | 날짜 · 시작 · 끝 · 대상·장소 · 한 일 · 특이사항 · 작성/수정 시각 |
| **일정** | 날짜 · 시간 · 메뉴 · 내용 · 작성/수정 시각 |
| **메뉴** | 메뉴 이름 · 색 (색 칸이 그 색으로 칠해집니다) |

- 숨겨진 **id · menu_id 열은 지우지 마세요.** (앱이 어느 줄인지 찾는 번호)
- 시트에 직접 줄을 적어도 나타납니다. 돌봄일지는 **날짜와 한 일**, 일정은 **날짜와 내용**만 있으면 됩니다.
  (일정의 메뉴 칸에 메뉴 이름을 적으면 그 메뉴로, 비우면 「일정」으로 들어갑니다)
- 스크립트 코드를 고쳤다면 `배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포`. 이렇게 해야 **주소가 바뀌지 않습니다.**

## 1-5. 말로 일지 채우기 · AI 연결 (AI 는 나중에 해도 됩니다)

일지 쓰기 화면 맨 위의 **🎤 말로 채우기** 버튼으로 말해서 일지를 씁니다.

| 상태 | 말로 채우기를 누르면 |
|---|---|
| **AI 연결 전** | 말한 내용이 「한 일」 칸에 그대로 들어갑니다. 칸에 내용이 있으면 아래에 덧붙입니다 |
| **AI 연결 후** | AI(Claude)가 시작 · 끝 · 대상 · 한 일 · 특이사항 칸으로 나눠 채우고, 내용이 있으면 살리면서 보완합니다 ("시작은 9시가 아니라 10시"처럼 고치기도 됨) |

| 버튼 | 하는 일 |
|---|---|
| **말로 채우기 / 말로 보완하기** | 누르고 말한 뒤 **말하기 끝** |
| **초기화** | 날짜만 남기고 칸을 비움 → 다음 마이크는 새로 작성 |
| **↶ 되돌리기** | 방금 채우기 · 보완 · 초기화를 취소 (직접 글자를 고치면 사라짐) |

- 말 → 글자: 휴대폰 앱은 안드로이드 음성 인식(처음에 마이크 권한 허용), PC 는 **크롬 · 엣지** 브라우저 음성 인식.
- 채운 내용은 **저장 버튼을 눌러야** 구글시트에 들어갑니다.

### AI 연결하기 (김태순 님 계정 · 한 번만)
1. https://console.anthropic.com 가입 → **Billing** 에서 크레딧 충전 → **Limits** 에서 월 사용 한도 걸기
2. **API Keys → Create Key** 로 키(`sk-ant-…`)를 만들고 복사
3. 앱(PC 또는 휴대폰) **설정 → AI 연결** 칸에 붙여넣고 **저장하고 AI 연결**
   → "AI 연결됨 · 키 sk-ant-…abcd" 가 나오면 끝입니다. PC · 휴대폰 모두 바로 AI 로 정리됩니다.

- 키는 **구글시트 스크립트 속성**(`ANTHROPIC_API_KEY`)에만 저장되고, 앱 · 기기 · GitHub 에는 남지 않습니다.
- 저장할 때 스크립트가 Anthropic 에 키가 맞는지 확인합니다 (요금 없음). 크레딧이 없으면 말로 채우기를 할 때 안내가 나옵니다.
- **키 바꾸기 · 연결 끊기**도 같은 설정 화면에서 합니다.
- 구글시트가 먼저 연결되어 있어야 합니다. 예전 Code.gs 를 쓰고 있었다면 새 Code.gs 를 붙여넣고 **새 버전**으로 배포해 주세요.

### 비용 · 개인정보
- 한 번 정리에 대략 **20~40원** (Claude Opus 5, 말 길이에 따라 다름). Anthropic 콘솔 **Usage** 에서 확인합니다.
- AI 를 연결하면 말한 내용이 정리를 위해 Anthropic 으로 보내집니다. API 로 보낸 내용은 AI 학습에 쓰이지 않습니다.
  어르신 성함 대신 "○○○ 어르신"처럼 말해도 됩니다.
- 체험 화면(`?demo`)에서는 AI 를 연결할 수 없습니다.

```bash
npm install

```

`.env` 에는 해설사 근무표 폴더의 `.env` 와 **같은 값**이 들어 있어야 합니다. (`.env.example` 참고)
특히 `VITE_PIN_PEPPER` 와 `VITE_LOGIN_EMAIL_DOMAIN` 이 다르면 같은 PIN 으로 로그인되지 않습니다.

## 3. 인터넷에 올리기 (Vercel)

GitHub · Vercel 은 **김태순 님 계정**이 소유하고, 작업자는 GitHub 저장소 **협업자(Collaborator)** 로 고칩니다.

1. 김태순 님 GitHub 에 **공개(Public) 저장소**를 만들고 이 폴더를 올립니다.
   - 공개여도 되는 이유: 올라가는 것은 화면 코드뿐이고, 돌봄 기록은 구글시트에 있습니다.
     `.env` · `release-key/` · 빌드 결과물은 `.gitignore` 로 막혀 있습니다.
   - **비공개로 하면 안 되는 이유**: Vercel 무료(Hobby) 요금제는 비공개 저장소에서
     소유자가 아닌 사람이 올린 커밋의 배포를 막습니다. (공개 저장소는 협업 무료)
2. 저장소 `Settings → Collaborators → Add people` 로 작업자 GitHub 계정을 초대합니다.
   (개인 계정 저장소는 권한을 고르는 칸이 없고, 초대받은 사람은 자동으로 수정 · push 할 수 있습니다. 작업자가 메일에서 **수락**해야 합니다)
3. 김태순 님 Vercel → `Add New… → Project` → 그 저장소 선택
4. `Environment Variables` 에 `.env` 의 값을 그대로 넣고 `Deploy`
   (`VITE_SUPABASE_URL` · `VITE_SUPABASE_ANON_KEY` · `VITE_LOGIN_EMAIL_DOMAIN` · `VITE_PIN_PEPPER` · `VITE_OWNER_NAME` · `VITE_SCHEDULE_URL` · 있으면 `VITE_SHEET_API_URL`)

이후 작업자가 `main` 에 push 하면 Vercel 이 자동으로 다시 배포합니다.

> 구글시트 · Apps Script 는 김태순 님 계정에만 둡니다. 스크립트를 고쳤다면 **배포 관리 → 새 버전** 은
> 김태순 님 계정으로 눌러 주세요. (편집자가 배포를 고치면 실행 계정이 편집자로 바뀔 수 있습니다)

## 4. 쓰는 법

| 하고 싶은 것 | 어떻게 |
|---|---|
| 오늘 일지 쓰기 | 위쪽 **＋ 오늘 일지 쓰기** |
| 말로 일지 쓰기 | 일지 쓰기 화면 맨 위 **🎤 말로 채우기** → 말하기 → **말하기 끝** (1-5 참고) |
| 90시간까지 남은 시간 | 캘린더 바로 위 **○월 돌봄 · 90시간까지** (시작 · 끝 시간을 넣어야 계산됩니다) |
| 오늘 일정 추가 | 위쪽 **＋ 일정** → 시간 · 메뉴 · 한 줄 내용 |
| 다른 날 쓰기 · 보기 | 캘린더에서 그 날짜를 누름 → **＋ 이 날 일정 추가** / **＋ 이 날 일지 쓰기** |
| 고치기 · 지우기 | 날짜를 누름 → 카드의 **수정** / **삭제** |
| 보고 싶은 것만 보기 | 위쪽 메뉴를 눌러 켜고 끄기 (여러 개 가능) · **전체**는 모두 켜기 |
| 메뉴 늘리기 · 색 바꾸기 | 위쪽 **✎ 메뉴 편집** |
| 긴 내용 끝까지 읽기 | 캘린더 칸에 전부 나오고, 아래 **○월 기록 모아보기**를 누르면 날짜순으로 펼쳐집니다 (기본은 접힘 · 펼친 기기는 다음에도 펼친 채로) |

**캘린더 표시** (색은 메뉴 편집에서 바꿀 수 있습니다)
- 근무 = 근무지 (점선 = 근무표에서 바뀐 근무, 안내 메모도 함께)
- 일정 = `● 시간 한 줄 내용` (길면 … 으로 줄임, 점 색 = 메뉴 색)
- 돌봄 일지 = 시간 · 대상 · 한 일 · 특이사항 전체 (왼쪽 선이 주홍색 = 특이사항 있음)
- 빨간 날짜 + 이름 = 공휴일 · 주홍 동그라미 = 오늘

**공휴일 표**는 [src/lib/holidays.ts](src/lib/holidays.ts)에 2025~2027년이 들어 있습니다.
설·추석처럼 해마다 날짜가 바뀌므로, 2028년이 되기 전에 다음 해를 덧붙여 주세요.

## 5. 안드로이드 앱 (APK)

### 만들기
```bash
npm run build
npx cap sync android
cd android
gradlew.bat assembleRelease
```
결과물: **`apk/돌봄근무일지.apk`** (빌드가 끝나면 자동으로 복사됩니다)

> 빌드 중간 파일은 OneDrive 밖(`사용자 폴더\.dolbom-android-build`)에 만듭니다.
> 프로젝트가 OneDrive 안에 있어 동기화가 파일을 붙잡으면 빌드가 실패하기 때문입니다.

### 휴대폰에 설치
1. APK 파일을 카카오톡(나에게 보내기) · USB · 구글 드라이브 등으로 휴대폰에 옮깁니다.
2. 파일을 누르면 "출처를 알 수 없는 앱" 허용을 묻습니다 → 허용 → 설치
3. 처음 한 번 PIN 으로 로그인하면 계속 유지됩니다.

### 웹페이지를 고치면 앱도 다시 설치해야 하나?
- **지금 방식 (화면을 앱 안에 담음)** — 네. 위 "만들기"로 새 APK 를 만들어 **덮어 설치**합니다.
  기록은 구글시트에 있으므로 사라지지 않습니다. 덮어 설치할 때마다 `android/app/build.gradle` 의 `versionCode` 를 1씩 올려주세요.
- **웹 주소 연결 방식 (권장, Vercel 주소가 생긴 뒤)** — `capacitor.config.ts` 에 아래를 넣고 APK 를 **한 번만** 다시 만들면,
  그 뒤로는 웹만 고쳐도 앱에 자동 반영됩니다.
  ```ts
  server: { url: 'https://(Vercel 주소)', cleartext: false },
  ```

### ⚠️ 앱 서명키 — 반드시 백업
`release-key/` 폴더(`dolbom-release.jks`, `keystore.properties`)는 APK 서명키입니다.
**잃어버리면 새 APK 를 기존 앱 위에 덮어 설치할 수 없습니다** (앱을 지우고 새로 설치해야 함).
저장소(GitHub)에는 올라가지 않도록 막아두었으니, 별도로 안전한 곳에 복사해 두세요.

```
google-apps-script/Code.gs    구글시트 저장소 · AI 연결 (구글시트에 붙여넣고 웹 앱으로 배포)
capacitor.config.ts           안드로이드 앱 설정 (앱 이름 · 웹 주소 연결)
android/                      안드로이드 앱 프로젝트 (아이콘 · 서명 설정)
release-key/                  앱 서명키 (저장소 제외 · 백업 필수)
src/
  App.tsx                     화면 배치 (보기 선택 · 달 넘기기 · 캘린더 · 모아보기)
  state/AppContext.tsx        로그인 · 근무(Supabase)/일지(구글시트) 불러오기 · 저장 · 새로고침
  pages/Login.tsx             김태순 님 PIN 4자리 (근무표 앱과 같은 계정)
  components/FilterBar.tsx    상단 보기 (여러 메뉴 켜고 끄기)
  components/Calendar.tsx     월 캘린더 (근무 · 한 줄 일정 · 돌봄 일지 · 공휴일)
  components/MonthList.tsx    이 달 기록 모아보기
  components/DayModal.tsx     날짜 상세 (근무 · 일정 · 일지 목록 · 수정 · 삭제)
  components/EntryForm.tsx    돌봄 일지 입력 (날짜 · 시간 · 대상 · 한 일 · 특이사항 · 말로 채우기)
  components/EventForm.tsx    한 줄 일정 입력 (날짜 · 시간 · 메뉴 · 내용)
  components/MenuEditor.tsx   메뉴 편집 (추가 · 지우기 · 색)
  components/SettingsModal.tsx 구글시트 연결 주소 · AI 연결 · 로그인 계정 · 로그아웃
  lib/voice.ts                음성 인식(휴대폰 · PC) · 말한 내용을 칸에 넣기
  lib/menus.ts                메뉴 규칙 (고정 메뉴 · 색 목록 · 보기 거르기)
  lib/holidays.ts             공휴일 표
  lib/demo.ts                 체험 화면(?demo) 예시 데이터
  lib/                        서버 통신 · 날짜
```
